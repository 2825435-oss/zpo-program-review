# Встановлення перевіряльника навчальних програм ЗПО

Версія **0.1.5**. Стабільний тег **v0.1.5**. Використовуйте файли з цього тегу або [ZIP цього релізу](https://github.com/2825435-oss/zpo-program-review/releases/download/v0.1.5/zpo-program-review-0.1.5-chatgpt.zip).

## Якщо ви встановлюєте в ChatGPT уперше

1. На комп’ютері натисніть [«Завантажити готовий ZIP»](https://github.com/2825435-oss/zpo-program-review/releases/download/v0.1.5/zpo-program-review-0.1.5-chatgpt.zip). У папці завантажень має бути файл `zpo-program-review-0.1.5-chatgpt.zip`. Якщо браузер розпакував архів, збережіть оригінальний ZIP повторно.
2. Відкрийте [ChatGPT](https://chatgpt.com/) під своїм акаунтом. Почніть новий чат у режимі **Робота (Work)**. У полі повідомлення наберіть `@Plugin Creator` і виберіть **Plugin Creator** зі списку. Якщо його там немає, знайдіть його в розділі **Плагіни** й установіть, якщо картка пропонує таку можливість.
3. Натисніть **«Додати файли й інше» → «Додати світлини та файли»**, виберіть ZIP і надішліть разом із цим текстом:

   > Збережи прикріплений ZIP як приватний плагін «Перевірка навчальних програм ЗПО» в моєму особистому акаунті ChatGPT. Використай файли пакета без змін. Дай посилання на картку плагіна й залиш доступ приватним.

4. Коли ChatGPT поверне картку саме **«Перевірка навчальних програм ЗПО»**, відкрийте її. Якщо є кнопка **«Встановити»**, натисніть її. Ознака успіху — плагін є в розділі **Плагіни → Встановлені**. На телефоні увійдіть у той самий акаунт, відкрийте картку або виберіть плагін через `@`, додайте PDF і напишіть «Перевір програму».

Якщо Plugin Creator недоступний у вашому акаунті або повертає тільки ZIP без картки, хмарне встановлення ще не підтверджене. Покажіть агенту відповідь Creator або точний текст помилки. Якщо в поточному чаті немає доступу до вебсторінки, відкрийте цю інструкцію в браузері й виконайте кроки вище.

[Документація ChatGPT про плагіни](https://learn.chatgpt.com/docs/plugins) · [Plugin Creator](https://learn.chatgpt.com/docs/build-plugins)

## Якщо цю інструкцію читає AI-агент

Визнач, чи потрібен ChatGPT з доступом із телефона, чи локальний Codex. Якщо користувач не вказав середовище і його не можна визначити, постав одне запитання. Перевір наявність плагіна й версію. Якщо потрібна версія вже встановлена, покажи, як її запустити. Для старішої хмарної версії використовуй оновлення наявної картки.

Якщо можеш зберегти ZIP у вибраному акаунті через підтримувану функцію, виконай установлення й поверни посилання на картку. Якщо можеш лише допомогти користувачу, дай пряме посилання на ZIP і назви **перший невиконаний крок** із маршруту вище. Підтверджуй встановлення після появи перевіряльника в розділі «Встановлені». Локальне встановлення Codex підходить для роботи на комп’ютері.

## Локальний Codex

Додайте каталог зі стабільного тегу й установіть плагін:

```sh
codex plugin marketplace add 2825435-oss/zpo-program-review --ref v0.1.5
codex plugin add zpo-program-review@zpo-education-tools
codex plugin list -m zpo-education-tools
```

Відкрийте новий сеанс, виберіть плагін і додайте програму. Ця інсталяція діє локально в Codex. Для хмарного акаунта застосовується процедура ChatGPT вище. [Документація про пакети й каталоги](https://developers.openai.com/plugins/build/plugins)
