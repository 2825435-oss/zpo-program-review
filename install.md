# Встановлення перевіряльника навчальних програм ЗПО

Версія **0.1.3**. Стабільний тег **v0.1.3**. Використовуйте файли з цього тегу або [ZIP цього релізу](https://github.com/2825435-oss/zpo-program-review/releases/download/v0.1.3/zpo-program-review-0.1.3-chatgpt.zip).

Якщо ви агент, спочатку визначте, де користувач хоче запускати плагін. Перевірте, чи вже є однойменний плагін та яка його версія. Якщо потрібна версія встановлена, покажіть, як її викликати. Якщо є попередня хмарна версія, використайте оновлення наявної картки, щоб не створювати дубль.

## ChatGPT, зокрема для подальшого використання з телефона

1. Завантажте ZIP релізу й відкрийте ChatGPT у своєму акаунті. У новому чаті Work виберіть `@Plugin Creator` та прикріпіть ZIP.
2. Попросіть зберегти ZIP як приватний плагін «Перевірка навчальних програм ЗПО», зберігши всі файли пакета. Якщо агент має підтримувану функцію приватного збереження, він може виконати цей крок і повернути картку. Якщо доступна лише локальна інсталяція або Creator не може зберегти плагін в акаунті, повідомте це прямо.
3. Відкрийте картку, встановіть плагін, якщо є кнопка встановлення, і перевірте його наявність у розділі «Встановлені». У тому самому акаунті на телефоні відкрийте картку або виберіть плагін через `@`.
4. Додайте PDF і напишіть «Перевір програму». У відповіді перевірте короткий підсумок годин та формат зауважень «Критерій / Місце / Пункт / Пропозиція».

[Документація ChatGPT про плагіни](https://learn.chatgpt.com/docs/plugins) · [Plugin Creator](https://learn.chatgpt.com/docs/build-plugins)

## Локальний Codex

Додайте каталог зі стабільного тегу й установіть плагін:

```sh
codex plugin marketplace add 2825435-oss/zpo-program-review --ref v0.1.3
codex plugin add zpo-program-review@zpo-education-tools
codex plugin list -m zpo-education-tools
```

Відкрийте новий сеанс, виберіть плагін і додайте програму. Ця інсталяція діє локально в Codex. Для хмарного акаунта застосовується процедура ChatGPT вище. [Документація про пакети й каталоги](https://developers.openai.com/plugins/build/plugins)
