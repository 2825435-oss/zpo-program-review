# Перевірка навчальних програм ЗПО

Плагін перевіряє структуру навчальної програми, реквізити, теми, нумерацію, розподіл годин та бібліографію. Він окремо звіряє тижневе й річне навантаження з навчальним планом. Зауваження подає українською у форматі «Критерій / Місце / Пункт / Пропозиція».

Поточна версія — **0.1.3**.

- [Завантажити ZIP на сторінці релізу](https://github.com/2825435-oss/zpo-program-review/releases/tag/v0.1.3).
- [Інструкція встановлення для користувача й агента](install.md).
- [Історія версій](CHANGELOG.md).

### Один запит до агента

> Прочитай https://raw.githubusercontent.com/2825435-oss/zpo-program-review/main/install.md і допоможи мені встановити плагін у моєму середовищі. Перевір, чи він уже встановлений.

Для приватного ChatGPT використовуйте ZIP із релізу й Plugin Creator, якщо функція збереження приватних плагінів доступна у вашому акаунті. Для Codex доступне локальне встановлення через каталог цього репозиторію.

Пакет містить правила й довідники. Навчальні програми, звіти перевірок і налаштування особистих акаунтів зберігаються окремо.
