# Навантаження за застосовним навчальним планом

1. Визнач напрям, рівень, рік навчання в межах рівня та профіль чи категорію об’єднання, якщо таблиця їх розрізняє. Перевіряй кожен рік і варіант окремо.
2. За наявності підтвердженого застосовного плану звір години на тиждень і на рік з його рядком і примітками. Для фіксованого числа перевір рівність, для діапазону — входження в межі включно. Враховуй лише підтверджені винятки. Не виводь річні межі з тижневих, якщо їх окремо наведено у плані.
3. Якщо застосовний план невідомий, порівняй з наказом № 676 довідково. Відхилення подай як питання для уточнення, а відповідність — як збіг із типовим рядком. Якщо бракує напряму, рівня, року, спеціальної категорії або доступу до рядка, прямо вкажи це. Для рядків поза витягом відкрий повний текст і примітки. Не підставляй значення з іншого рядка.
4. У підсумку покажи обидва значення програми, межі рядка і джерело. За відхилення вкажи, яке число поза межами. Веди арифметичну перевірку тривалості окремо.
